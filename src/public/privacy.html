Privacy

Last updated: 19 September 2026

TableJSON processes PDFs you send to tablejson.com so we can extract tables and return JSON. This page explains what that involves.

Files you upload

Playground and API requests send the PDF to our server for that request only. We read the text layer, build the table JSON, and return it. Uploads are not kept as a document library after the request finishes.

What we look at

We read text already in the PDF so we can find tables. We do not sell upload contents. Server logs may include request time, status, and size for reliability.

Accounts and keys

The public playground on this site does not need an API key. Direct API and Zapier use require a key you configure. RapidAPI users authenticate through RapidAPI.

Contact

Privacy questions go to the Cloudflare contact address for this domain.
