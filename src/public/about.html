About

TableJSON turns tables in text-layer PDFs into clean JSON. Upload a file on the playground, or call the API from RapidAPI, Zapier, or your own HTTP client.

What it does

  • Reads the PDF text layer and finds tables
  • Returns headers, rows, and page numbers as JSON
  • Works on digital PDFs up to 500 MB

It does not OCR scanned or image-only PDFs. Those files have no text layer to extract.

How to use it

The site at tablejson.com is the playground. API docs are at /openapi.json. This product is separate from HidePDF Content, which hides sensitive values in PDFs.
