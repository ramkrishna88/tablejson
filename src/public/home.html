PDF tables, returned as JSON

TableJSON reads the text layer of a PDF, finds the tables, and returns headers, rows, and page numbers. Use it from the playground, RapidAPI, Zapier, or your own HTTP client.

Open playground API reference

What you get

  • Structured tables with headers and row objects
  • Page start, page end, and total page count
  • Files up to 500 MB
  • No customer login — API keys are issued to callers

It does not OCR scanned or image-only PDFs. Those files have no text layer to extract.

Ways to use it

  • Playground — upload a PDF in the browser, no key required
  • API — POST /v1/extract-tables with X-API-Key
  • Zapier — connect a TableJSON key and extract tables in a Zap

This product is separate from HidePDF Content, which hides sensitive values in PDFs. Contact: hello@tablejson.com.
