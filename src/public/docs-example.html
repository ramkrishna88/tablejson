Example extract response

This is the RapidAPI Hub sample. It shows the same JSON shape as a live extract, without parsing a PDF.

What to send

Method: POST /v1/example

Body (JSON):

{"file":"https://tablejson.com/sample-mini.pdf"}

The file URL is only an example. This route ignores the file and returns a canned 2-row table so Chrome does not freeze.

What you get

  • status: success
  • tables_found: 1
  • Two rows: Hosting $1250.00 and Licenses $4500.00
  • Fields: page_number, page_end, data, raw_cells

Live PDF

To extract a real table, use POST /v1/extract-tables and upload a text-layer PDF, or send a public PDF URL. Mini file: sample-mini.pdf.

Full API docs: tablejson.com/docs.
