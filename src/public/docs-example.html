Example

Extract response

This is the RapidAPI Hub sample. Same JSON shape as a live extract, without parsing a PDF.

What to send

Method: POST /v1/example

Body: {"file":"https://tablejson.com/sample-mini.pdf"}

The URL is only an example. This route ignores the file and returns a canned 2-row table so the browser stays light.

What you get

  • status: success
  • tables_found: 1
  • Hosting $1250.00 and Licenses $4500.00
  • page_number, page_end, data, raw_cells

Live PDF

For a real table, use POST /v1/extract-tables with a text-layer PDF, or send a public URL. Mini file: sample-mini.pdf.
