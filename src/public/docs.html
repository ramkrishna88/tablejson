API documentation

TableJSON extracts tables from text-layer PDFs and returns clean JSON. Use the playground, RapidAPI, Zapier, or a direct HTTP call.

Fastest RapidAPI test

  1. Open POST Example extract response
  2. Leave the JSON body as the mini PDF URL
  3. Click Run
  4. Open Response — you should see a 2-row sample (Hosting, Licenses)

That example does not parse the PDF, so Run stays fast. Full notes: example playground docs.

Live extract

Use POST /v1/extract-tables for a real PDF.

  • Multipart field file — upload a PDF
  • Or JSON body {"file":"https://…"} — public HTTPS URL

Small test file: sample-mini.pdf. Larger sample: sample.pdf.

Auth

  • RapidAPI testers: send only X-RapidAPI-Key
  • Direct callers: send X-API-Key or Authorization: Bearer

Endpoints

  • GET /v1/health — API is up
  • POST /v1/example — tiny 2-row sample, no PDF parse
  • POST /v1/extract-tables — live table extract

Machine-readable spec: /openapi.json. Contact: hello@tablejson.com.
