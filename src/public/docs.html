API reference

TableJSON extracts tables from text-layer PDFs and returns JSON. Base URL: https://tablejson.com. Machine-readable spec: /openapi.json.

Authentication

The playground is same-origin and does not need a key. Direct API, RapidAPI, and Zapier calls do.

  • Direct API: send X-API-Key: YOUR_KEY or Authorization: Bearer YOUR_KEY
  • RapidAPI: send only X-RapidAPI-Key
  • Zapier: paste the same API key in the integration connection

Request a key at hello@tablejson.com. There is no customer login. Keys are issued to callers; the website itself does not require an account.

GET /v1/health

Confirms the API is up. No file and no key required.

curl https://tablejson.com/v1/health
{
  "status": "ok"
}

GET or POST /v1/example

Returns a tiny 2-row sample so testers can see the extract JSON shape without parsing a PDF. POST accepts a JSON body; the file URL is ignored. Details: example playground docs.

curl -X POST https://tablejson.com/v1/example \
  -H "Content-Type: application/json" \
  -d '{"file":"https://tablejson.com/sample-mini.pdf"}'

POST /v1/extract-tables

Live extract of every table in a text-layer PDF. Scanned or image-only PDFs are not supported.

Parameters

  • file (required) — multipart PDF upload, or JSON {"file":"https://…"} with a public HTTP(S) URL

Small test file: sample-mini.pdf. Larger sample: sample.pdf. Limit is 500 MB.

Example request (URL)

curl -X POST https://tablejson.com/v1/extract-tables \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"file":"https://tablejson.com/sample-mini.pdf"}'

Example request (upload)

curl -X POST https://tablejson.com/v1/extract-tables \
  -H "X-API-Key: YOUR_KEY" \
  -F "file=@invoice.pdf"

Example response

{
  "status": "success",
  "filename": "example.pdf",
  "total_pages": 1,
  "tables_found": 1,
  "metadata": { "execution_time_ms": 12, "extraction_mode": "text" },
  "tables": [
    {
      "table_id": 1,
      "page_number": 1,
      "page_end": 1,
      "headers": ["date", "item", "amount"],
      "total_rows": 2,
      "rows": [
        {
          "row_index": 1,
          "data": { "date": "2026-01-05", "item": "Hosting", "amount": "1250.00" },
          "raw_cells": ["2026-01-05", "Hosting", "1250.00"]
        }
      ]
    }
  ]
}

Errors

  • 400 — missing file, not a PDF, empty file, or bad URL
  • 401 — missing or invalid API key on protected routes
  • 413 — file too large
  • 429 — rate limited

Zapier

The TableJSON Zapier action calls POST /v1/extract-tables with the connected API key. Use a text-layer PDF from a previous Zap step.
