What TableJSON does with a PDF

TableJSON reads a PDF that already contains real text, finds the lines that look like a table, and returns those rows as JSON. Drop a PDF on the left card and press Extract. The Results panel fills with a collapsible JSON tree and a paged table. Copy JSON or Download JSON leaves the response on your computer.

The right card is only for invoices. Preview shows the pages. Extract downloads an Excel workbook and shows a checksum next to the line items. The checksum compares quantity times unit price with the line amount, then compares lines, tax, shipping, and discount with the total printed on the invoice. PASS means the arithmetic closed. FAIL still downloads the workbook, with the reason on the sheet, so a bad read does not pretend to balance.

Use it in four steps

  1. Confirm the PDF has a text layer. Open it and try to highlight a price. If the number highlights, TableJSON can read it. If the page is a picture of paper, stop. This site does not OCR.
  2. Drop the file on Extract tables to JSON, or press Try sample PDF to run sample.pdf. The file name and size show under the drop zone when it is ready.
  3. Press Extract. Latency, table count, and row count land in the three boxes. The table view shows 50 rows at a time. Download JSON for every row.
  4. For an invoice, use the right card. sample-invoice.pdf shows a checksum before you use your own file. The workbook has an Invoice sheet and a Raw extract sheet.

A direct call is the same extract without the browser. POST /v1/extract-tables takes the PDF in a multipart field named file. The playground on this host does not ask for a key. A script, Zapier, or RapidAPI call sends X-API-Key. See the API reference and the API guide.

Where it earns its keep

Accounts teams pull line items out of digital invoices. The invoice card looks for headers such as description, item, qty, unit price, rate, and amount. Vendor, invoice number, and invoice date come from labels on the first page, including "Invoice No" and "Billed by". Currency is read from codes such as USD, EUR, GBP, and INR, or from a symbol. Tax, shipping, freight, discount, and the stated total are taken from rows whose label is that word.

Bookkeepers turn statement PDFs into rows they can sort. There is no separate bank parser. You extract, then check the running balance yourself. A blank debit or credit is easy to lose, because empty cells are dropped when a line is split. The bank statement guide shows that. If a source system can export CSV, prefer that. TableJSON is for the file you were sent.

What it will not do

Scanned and image-only PDFs are out. The text-layer guide shows how to tell them apart in Preview or Chrome. Columns come from the text, not from ruling lines. A line splits on a tab, a pipe, two or more spaces, or, last, commas. The first multi-cell line becomes the header. Later lines with about the same cell count are data. "Unit Price" becomes unit_price. Each row keeps data and raw_cells. If nothing looks like a table, you get one fallback table with line_number and extracted_content. That is the document text, not a hidden grid. Merged cells and a title in the first row are the usual reasons a result looks shifted. Cleaning messy table JSON walks through those.

Values stay strings. 00120 is not turned into 120, and 1,250.00 is not parsed. Convert numbers when you know whether the file uses a US or European decimal. Uploads can be 500 MB. A public URL, sent as {"file":"https://..."}, stops at 50 MB. The API allows 20 extracts a minute per IP, and a single request can run for about three minutes.

What happens to the file

The PDF is sent here for that request. A multipart upload is written to a temporary file, read into memory, and deleted when the response finishes. It is not put in a database or a document library. A URL fetch stays in memory for the request. Logs can include time, path, status, size, and IP address, not the document itself. If the process is killed mid-request, a temp file can sit until the platform clears it. Cookies and the Google AdSense disclosure are on the privacy page.

Questions

Does TableJSON OCR a scanned PDF?

No. It reads the text layer only. A scan needs to be recognized somewhere else first. An invoice scan comes back as FAIL: no text layer, and the Excel file still downloads.

Do you keep my PDF?

A multipart upload is a temporary file for that request and is deleted when the response is sent. It is not added to a document library. URL fetches stay in memory for the request.

Do I need an account?

The playground on tablejson.com does not. A direct API call, Zapier, or RapidAPI does. There is no customer login on this site. Write to hello@tablejson.com for a key.

Why is the JSON one column, or a line_number table?

The text did not split into columns. That happens with scans, with words that are not spaced like a table, and with borders that are drawings rather than text. Check the PDF, or export CSV from the system that made it.

Can I get Excel or CSV?

Invoices download as .xlsx from the right-hand card or from POST /v1/invoice-xlsx. Add ?format=json for the checksum preview. Other tables return JSON. Turn the rows into CSV yourself. See JSON vs CSV.

What are the size limits?

500 MB for an upload. 50 MB when you send a URL. Twenty extract requests a minute per IP on the API.
