These are the notes I wish a PDF had shipped with. TableJSON reads a text layer and returns rows. The playground is enough for one file. The pages below are for the second file, when the header is wrong, the statement has a blank credit column, or you are about to loop the API over a folder.

Each guide uses the real response shape: headers, raw_cells, page_number, page_end, and, for invoices, the PASS or FAIL checksum. Nothing here describes an OCR mode. There is not one. If you only remember a single check, highlight a number in the PDF before you upload it.
