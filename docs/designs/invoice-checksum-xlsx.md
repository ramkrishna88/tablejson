### v1 schema (one generic AP layout)

One `tax` column. GST/VAT split is post-trigger.

Header (first-page extra-table text first; empty allowed except invoice number):

| Field | v1 source |
|---|---|
| vendor | First-page text: same line as `from` / `vendor` / `supplier` / `billed by`, else next line. Else empty. |
| invoice_number | Same/next line as `invoice no`, `invoice #`, `inv #`. If missing: still download; overall FAIL `invoice_number missing`. |
| date | Same/next line as `invoice date` only (not bare `date` if the line matches `due date` or `terms`). ISO if parseable, else raw string, else empty. |
| currency | Detected from totals region per Money parse. If none: overall `FAIL: currency unknown`. |

Line items from the largest table on the invoice pages. Columns:

- `description`
- `qty`
- `unit_price` (not unit of measure)
- `amount`

Column aliases: normalize both extract headers and aliases (lowercase, strip punctuation, `_` and space equivalent) then match. Aliases: description/item/particulars; qty/quantity; unit_price/rate/price; amount/line_total/linetotal/net/value. Match after removing spaces and `_` so `line_total` binds `Line Total`. If a required line column is missing after normalize, the file is **unmapped** (counts against 8/10), not an empty sheet.

Largest table = max `total_rows`; tie → lowest `table_id`.

Drop rows whose **normalized** description equals any addend label (same table as Checksum addends, including grand total, delivery, sub total, amount due, balance due). Prefer that table. Do not use a second regex.

Line check: parse qty as a decimal (not minor units). `round(qty * unit_price_minor) == amount_minor` within ±1 minor unit. Fail that cell only. Totals FAIL is independent.

**Near a label:** same line, else the next line only. Do not use bare `date` if the line also matches `due date` or `terms`.

### Money parse (to signed integer minor units)

1. Detect currency in order: dropped total-block rows, then the stated-total line, then page-1 lines. Tokens: `USD`, `INR`, `GBP`, `EUR`, `JPY`, `KRW`, `£`, `$`, `₹`, `¥`, `₩`. If none: overall `FAIL: currency unknown`. Do not default USD. Drop BHD/KWD (not in detect list).
2. Exponent: JPY/KRW 0, else 2.
3. Strip currency tokens. `(amount)` → negative. If both `.` and `,` exist, the last is decimal. If only commas, treat as thousands (`1,234` → 1234). Then, for INR only, strip remaining lakh grouping.
4. Compare integers. Totals PASS iff `|remainder| ≤ 1` minor unit.

### Checksum addends

Value of a dropped total-block row = last numeric cell on that row.

| Addend | Labels (normalize as above) |
|---|---|
| shipping | shipping, freight, delivery |
| discount | discount, less discount |
| tax | tax, vat, gst, sales tax |
| subtotal | subtotal, sub total |
| stated total | preference: amount due, then balance due, then grand total, then total |

`other` = remaining dropped total-block rows that are not shipping, discount, tax, subtotal, or stated total.

After money parse, `signed_discount = -abs(discount)`. Shipping and other stay as parsed. If a dropped shipping amount is already negative, keep that sign (do not abs).

`tax` = document tax row only. If none, `tax = 0`. No per-line tax fallback (v1 has no per-line tax column).

Identity (integers):

`sum(line amounts) + shipping + other + signed_discount + tax - stated_total = remainder`

FAIL copy: `FAIL: lines+shipping+other+discount+tax = {expected}; stated total = {stated}; remainder = {delta}`.

If a subtotal label exists, also `sum(line amounts) - subtotal` as an extra footer line. That miss does not set a second overall status.

One workbook status: `PASS` only if `invoice_number` exists **and** totals PASS. Else `FAIL` with the specific copy.

### Excel contract

Always two sheets, including PASS.

Sheet1 `Invoice`:

- Rows 1–6 metadata: vendor, invoice_number, date, currency, stated_total, checksum status.
- Row 7 line headers: description, qty, unit_price, amount, line_check.
- Row 8+ items.
- Freeze panes at `A8`.
- Footer starts at the first empty row after items: shipping, other, discount, tax, stated_total, expected_total, remainder, checksum (`PASS`/`FAIL`). Subtotal line only if a subtotal label existed.
- Any FAIL: red fill on that status cell and the numeric delta cells.

Sheet2 `Raw extract`: original tables plus page-1 lines, always present.

### Empty and scan behavior

- No text layer = parsed text empty after trim. Still download `.xlsx`. Sheet1 `FAIL: no text layer`. No OCR. No model.
- Fallback dump tables (extract putting all text in one table) are not “no tables.” Treat as unmapped if required line columns missing: checksum `FAIL: no line table`.
- Extract throw: same file, `FAIL: extract error` plus the safe error message (no stack).

### Mapping stop rule

Collect 10 mixed ChatGPT-paste PDFs. Evaluate 8/10 only on the **text-layer subset**. If that subset is fewer than 8 files, stop and say not enough digital fixtures (OCR decision waits on the 20-file upgrade trigger).

Mapped = `invoice_number` present + all four line columns bound after normalize + ≥1 line row remaining after drops.

If fewer than 8 of those digital fixtures map without a model, do not ship the playground. Change approach instead of widening heuristics forever.
